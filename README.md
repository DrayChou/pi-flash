Pi Flash ： Windows上的极速 Pi coding agent！

![pi-flash 演示动画](docs/images/pf-intro.gif)

▶ 同款演示另有**带音轨完整版**（17s mp4）：[docs/images/pf-intro.mp4](docs/images/pf-intro.mp4)

```bash
npm install -g pi-flash@latest   # 安装与更新
pi-flash                                # 启动
```
需要 Node.js ≥ 22.19
> 平台范围：**仅 Windows x64**
