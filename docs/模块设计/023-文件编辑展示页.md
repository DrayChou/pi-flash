## 编辑器底座（2026-10-07 拍板）

**不语义自研，简化对齐 zed。** 文本缓冲区/光标/undo/IME 不自己写，
用 gpui-component 0.2.0（已在依赖；构建在 Zed 的 gpui 框架上的组件库，
当前 app 只用了它的 Scrollbar）Input 的 **CodeEditor 模式**：

- 多行编辑 + 行号 + tree-sitter 语法高亮（Zed 同款高亮技术）+ tab 设置
- 内置搜索弹层：搜索 + 替换，行为对齐 zed buffer search（Ctrl+F）
- 我们做的是**对齐工作**：键位、编辑行为、外观对齐 zed editor；
  砍掉 LSP、多光标、补全、悬浮文档等高级功能
- 高亮语言仅 9 种（rust/ts/js/go/json/html/markdown/zig），
  其余语言纯色显示，可接受

## 默认约定（有异议再改）

- 保存 Ctrl+S；未保存修改 tab 显示脏标记圆点；关闭脏标签弹确认
- 外部改动检测（notify 已在依赖）：缓冲区无未保存修改 → 自动重载；
  有修改 → tab 标记冲突，等用户确认重载（Zed 行为）。**监听面 = cwd 递归
  watch + cwd 外打开文件按所在目录单挂非递归 watch**（Zed 为 workspace
  外文件建 single-file worktree 同款）：此前 cwd 外文件（Obsidian 库 /
  远程 FILE_OPEN）根本没监听，磁盘改了不跟。重载用 `reload_value`——
  保留阅读位置/光标（Zed 的外部 reload 保留 anchor；set_value 是程序化
  赋值语义，会把光标扔到文末、滚动归零）；markdown 预览同理不因块数变化
  跳回顶部，且**有未保存修改时预览渲染缓冲区**（Zed preview 读 buffer，
  不是磁盘文件）
- 二进制/超大文件（>10MB）提示不打开
- 面包屑 = 项目根相对路径段，可点击逐级导航（对齐 zed）；**工作区外文件
  退化为绝对路径，Windows 盘符前缀与根合为一段（`D:\` 一个 crumb，
  不再是 `D:` + `\` 两段）**——分段与累积路径由
  `content::breadcrumb_segments` 单一实现，渲染与自动化快照共用
- **自动回行（soft wrap）全程开启**：md 预览靠块内容段 `min_w(0)` 拿到
  确定宽度自然折行（zed markdown 同款 `min_w_0`）；源码编辑走
  vendored gpui-component 的 `soft_wrap(true)`（增量折行，未折行时仍是
  等高行快路径）——2026-10-10 用户口径「预览和编辑状态都要回行」

## 搜索条三连修（2026-10-11，用户验收驱动）

1. **面板黑底**：`sync_gpui_tokens` 漏映射 gpui-component 的
   `popover/popover_foreground/secondary_*`——它们停在 `theme::init()`
   按系统外观加载的默认盘，浅色主题遇系统深色 = 面板 `#0a0a0a` 纯黑、
   ghost 图标白字。现按应用 token 映射（popover 留给 tooltip/菜单；
   popover 相对 bg_panel 混 4% text 抬升——`mix_rgb(a,b,wa)` 的 wa 是
   **a** 的权重，主色放第二参）。
2. **样式对齐 zed（2026-10-11 二轮口径）**：搜索条全宽平贴、背景
   = `editor_background()`（与上方面包屑操作栏同色，非浮卡）；撤
   popover 底/圆角/下边框；搜索/替换输入框升 Medium（32px），面板按钮
   xsmall→small；全部按钮加本地化 tooltip（区分大小写/切换替换/上下
   个匹配含快捷键/关闭），文案在组件 `locales/ui.yml`，locale 随
   `i18n::set_lang` 同步（繁体走组件 zh-HK 桶）。
3. **结构归位（2026-10-11 三轮口径：搜索框是操作栏的一部分）**：面板
   不再挂在编辑器 TextInput 顶部（vendor `text_input.rs` 摘掉
   `.children(search_panel)`，升级重放时勿漏），改由 app 操作栏
   `file_nav_bar` 作为第二行渲染（`InputState::search_panel_element()`
   返回面板 Entity 元素 + `search_panel_open()` 控制占位）——面包屑行
   与搜索行同块同底色，× 与右侧图标列同缘，Esc 收起整行。
   `file_nav_bar` 为此增 `cx` 参数。
2. **面板打不了字**：app 的帧级焦点仲裁（render 每帧回收焦点给
   composer）不认识搜索面板的输入框——它不是编辑器本体的
   focus_handle。vendor 补丁：`SearchPanel::inputs_focused` +
   `InputState::search_panel_focused`（均在 `input/search.rs`，升级
   重放）；`Chat::file_editor_focus` 把面板持焦视同编辑器持焦。
3. **按钮全空白**：SearchPanel 的 Aa/替换/‹/›/× 用 gpui-component 的
   `IconName`（`icons/*.svg`），上游 crate 不带 assets，宿主 app 的
   `Assets` 没嵌 → 钮渲染成空壳。补嵌 4 枚 lucide 图标
   （case-sensitive/replace/chevron-left/close，源：上游
   crates/assets/assets/icons，jsdelivr 可达时随升级对账）。
4. 自动化：`input.focus` 增 `editor` 目标（Ctrl+F 类「焦点在编辑器才
   生效」的键位断言入口），见 000-自动化测试.md。
