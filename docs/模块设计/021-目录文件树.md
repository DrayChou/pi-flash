## 拖拽移动（Zed project_panel drag_and_drop 移植）

gpui 窗口内 DnD 三件套挂树行（`on_drag` 发起 / `drag_over` 落点高亮 / `on_drop`
提交），payload = `TreeDrag { path, is_dir }`，落点语义与幽灵视图在
`function_panel/file_tree_drag.rs`。

- **落点语义（Zed move_worktree_entry 同款）**：悬停目录行 = 移入该目录；
  悬停文件行 = 移到其父目录；列表空白处 drop = 移到项目根；钉住祖先链上的
  目录行也是合法目标。
- **真实移动判定** `drag_move_target`：原地（拖回所在目录）、进自身子树、
  拖到自己身上 → None（不高亮、drop 静默 no-op）；drop 与高亮同源。
- **悬停自动展开**：折叠目录行悬停 500ms 自动展开（Zed hover_expand 同款），
  目标去重靠 `ws.tree_drag_expand`，离开该行即清。
- **移动提交** `tree_move_commit`（file_actions）：fs::rename（Windows 跨盘
  报错、无复制降级，Zed 同）+ 打开面重映射（tab/缓冲/待聚焦/展开集合，与
  改名提交共用 `remap_moved_entry`）+ 目标链沿途展开 + refresh_git。
  目标重名报错不覆盖。
- **点击语义变更**：行主动作（展开目录/打开文件）从 on_mouse_down 改挂
  on_click（mouse-up）——gpui 的 click 与 drag 天然互斥（位移超 2px 进
  drag），按下即触发的旧写法会在拖拽起手时先行展开/打开。变更列表
  （只看变更）与行内改名态不接拖拽。
- 已知边界：vendored gpui 0.2.2 无 external_drag_payload 一族 API，窗口内
  拖不出去到资源管理器（Zed 有）；Ctrl 复制拖拽（Zed copy 修饰键）未做。

## Pin 功能 ：收藏目录或文件到 Pin收藏夹
文件树下内容过多时，用户只关注几个目录或文件时，是用PIN将指定目标纳入收藏夹

1、操作栏 加 Pin icon，放置在【只看变更】左侧。点击后整个树体区域切换为
Pin收藏夹视图（与【只看变更】同级的独立面板，本质是文件树过滤器）。

2、目录及文件菜单增加 Pin，见上方。点击后加入Pin收藏夹

3、unPin：右键菜单「取消固定」（已收藏条目的菜单项即取消固定）；取消最后
一个收藏自动退回文件树视图

视图语义（021 三改定稿）：
- 操作栏 Pin / 只看变更两颗钮 = **视图切换钮**：树视图下显示各自功能
  icon，进入对应视图后 icon 换成目录树（accent 高亮，tooltip 返回目录树）
  ——「点击回目录树」语义
- 根条目按名称字母排序，文件夹和文件一律名称在前，路径淡化显示在后
- 收藏的目录可展开（展开集合与主树共享），子级完整子树；行渲染/右键菜单/
  拖拽/git 徽标/F2 改名全部与文件树一致
- 与【只看变更】互斥（同一树体区域三视图：树/变更/Pin）；行内新建回退树
  模式；空收藏点击 Pin 钮不切换（无空态提示）；视图会话态不持久化，启动
  默认文件树
- 收藏清单 per-project 持久化（workspace.json `__pins`），改名/移动跟随、
  删除清理、切项目换清单
