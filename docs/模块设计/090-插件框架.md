# PF 插件框架(090)

> 宿主应用(Pi-Flash)自身的插件体系,类似 Obsidian:插件扩展**桌面应用本身**
> (功能面板视图/设置页/数据/宿主服务),与 pi 的扩展(package)是两套东西。
> 定稿日期:2026-10-11。参考实现:Zed extension 体系(`D:\github\zed`
> crates/extension,基线 4c902c9)+ Obsidian 插件模型。

## 0. 命名与边界(与 040/041 划清)

| | pi 的 package | PF 的插件 |
|---|---|---|
| 中文名 | **扩展**(040 已改名) | **插件** |
| 扩展的是 | agent 能力(工具/提示词/skill) | 桌面应用 UI/功能(面板/设置页) |
| 运行位置 | node 进程内(vendored pi) | wasm 沙箱(宿主进程内) |
| 设置入口 | settings-扩展(TAB_PLUGINS) | settings-插件(新 tab) |
| 本文档 | 040 / 041 | 本文 |

**v1 范围(拍板)**:
- UI 开放面 = **功能面板(dock)视图 + 插件自有设置页**,插件第一步只能围绕功能面板定制功能(样板:git 面板);
- **不提供任何 pi 能力**(pi RPC / spawn 参数 / settings.json 一律不暴露,黑名单写死);
- 自带**插件市场安装界面**:后端 = Gitee 插件中心仓库(索引 + 多插件项目 monorepo),读索引展示、自动下载安装;
- 运行时 = **WASM**(wasmtime,Zed 同路)。

## 1. 总体架构

```
插件项目(独立仓库,Rust → wasm32-wasip1)
   依赖 pf-plugin-sdk(ElementSpec builder + JSON ABI helper)
   产出 plugin.toml + <id>.wasm
                ↓ 安装(~/.pi-flash/plugins/<id>/)
crates/plugin-api        稳定契约(不依赖 gpui/app)
├── manifest.rs          plugin.toml schema 解析 + 校验
├── elem.rs              ElementSpec / Event / Action 类型(serde)
└── version.rs           api_version 常量;wasm custom section 解析

crates/app/src/plugins/  宿主实现
├── mod.rs               PluginRegistry:发现/启用状态/生命周期
├── runtime.rs           wasmtime Engine/Store/Instance;epoch 超时;trap 隔离
├── bridge.rs            导出函数调用(load/render/on_event/on_result)
├── host_api.rs          宿主函数实现(全部 capability 校验 + 审计)
├── ui.rs                ElementSpec → gpui(闭合组件库,主题令牌注入)
├── dock.rs              dock 视图注册(与内置 PanelTab 共存)
├── settings_page.rs     settings 动态 tab(排在固定 tab 之后)
└── marketplace.rs       索引拉取/缓存/下载/SHA-256 校验/安装/更新
```

**铁律:插件永远不接触 gpui、不接触 AgentSession、不执行进程、不读写任意路径。**
一切经 host 函数收口(§4),插件代码只是"算出一棵 UI 树 + 处理事件"。

## 2. 运行时(wasmtime)

| 项 | 决定 | 理由 |
|---|---|---|
| 目标 | wasm32-wasip1(裸 core module,非 component model) | JSON ABI 最简;component model 生态仍在动,不上 |
| ABI | 导入/导出均为 `string`(JSON)进出 + wasm memory 拷贝 | SDK 只需 serde;版本演进宽松 |
| WASI | 空 ctx:仅 clock/random,无 preopens、无网络、无 env | 文件网络全走宿主函数,可审计 |
| 隔离 | 每插件独立 Store/Instance;trap 只杀该插件 | 自动禁用 + 错误横幅,不崩 app |
| 超时 | epoch interruption:导出调用硬超时 100ms(render)/1s(on_event) | 死循环插件冻不住 UI |
| 调用线程 | cx.background_executor;结果回主线程 apply | 不阻塞渲染 |
| 体积代价 | wasmtime 精简 feature(cranelift only)≈ +10~15MB exe | 可接受(exe 已 70MB) |

### 2.1 导出函数(宿主调插件)

```
load()                      -> {"dock_items":[...], "settings_tabs":[...]}
render(view_id, ctx)        -> ElementSpec JSON
on_event(view_id, event)    -> Action[] JSON
on_result(req_id, payload)  -> Action[] JSON   (异步服务结果回灌)
```

### 2.2 导入函数(插件调宿主,全部校验 capability)

```
host_log(level, msg)
host_data_get(key) -> value        host_data_set(key, value)   // 插件私有 data.json
host_notify(level, title, body)
host_invalidate(view_id)           // 状态变了,请求宿主重调 render
```

**异步服务走 Action 不走回调**:插件 on_event 返回 `{"op":"service",req,name,op,arg}`,
宿主后台执行(git 等),完成后调 `on_result(req, payload)`。导出执行期间**禁止重入宿主回调**,ABI 简单一半。

### 2.3 API 版本化(照抄 Zed)

- wasm 自定义段 `pf:api-version`(3×u16 BE = 语义版本),宿主**先 wasmparser 全量扫后加载**
  (绕 wasmtime 对非法字节 panic 的坑,zed extension.rs:191 同款);
- manifest 门槛:`min_api_version`(插件 API)+ `min_app_version`(宿主版本),双检不过拒装拒启。

## 3. manifest(plugin.toml)

```toml
schema_version = 1
id = "git-panel"              # 唯一;= 安装目录名;^[a-z0-9-]+$
name = "Git 面板"
version = "0.1.0"
description = "功能面板 Git 视图"
authors = ["..."]
repository = "https://gitee.com/bl_ddyy/pi-flash-plugins"
min_app_version = "0.1.0"
min_api_version = 1
entry = "git_panel.wasm"      # 相对插件目录
capabilities = [              # 宿主按声明放行 host 函数/服务
  "ui:dock",                  # 注册 dock 视图
  "ui:settings",              # 注册设置页
  "data",                     # host_data_get/set
  "service:git",              # git 宿主服务(见 §5)
]
```

**能力模型**:manifest 声明 → host 函数入口逐调用校验(未声明即拒,记审计日志
`~/.pi-flash/plugins/audit.log`)。v1 能力封闭集就是上面 4 个;未来扩展位:
`net:http`、`process:exec`(Zed 同款 allowlist 式,见 zed capabilities/)。
**永久黑名单(不进能力枚举)**:pi 相关一切、fs 任意读写、spawn。

## 4. UI 模型:ElementSpec(宿主渲染,插件只描述)

GPUI 的 render 是编译期 Rust,插件画不了 UI → **声明式元素树,宿主闭合组件库渲染**。
附带收益:主题令牌自动一致(006 外观体系直接生效),插件无法伪造系统确认框。

### 4.1 组件闭合集(v1,约 14 个)

```
v_stack / h_stack(gap, align, pad)
text(content, style: body|label|title|mono|caption, color: token名)
icon(name)                    # 宿主 icon theme 取名
button(id, label|icon, variant: primary|secondary|ghost|danger, disabled)
input(id, placeholder, value, mono)
switch(id, checked)
tabs(id, items[], active)
list(id, rows: ElementSpec[], empty_hint)   # 宿主 virtual uniform_list(几百文件不卡)
badge(text, tone) / divider / spacer
```

组件集封闭,新增走 api_version 升级,插件不得自绘 canvas。

### 4.2 ElementSpec 示例(git 面板头部)

```json
{"t":"h_stack","gap":8,"children":[
  {"t":"text","content":"pi-flash","style":"title"},
  {"t":"spacer"},
  {"t":"tabs","id":"view","items":["Changes","History"],"active":0},
  {"t":"badge","content":"3","tone":"accent"}
]}
```

### 4.3 事件 / Action

```jsonc
// 宿主 → 插件
{"kind":"click","id":"commit_btn"}
{"kind":"input","id":"commit_msg","value":"fix: ..."}
{"kind":"tab","id":"view","index":1}
{"kind":"row_click","id":"files","index":3,"row":"src/main.rs"}

// 插件 → 宿主(Action[])
[{"op":"invalidate","view":"git-panel:changes"},
 {"op":"data_set","key":"msg_history","value":"[...]"},
 {"op":"notify","level":"info","title":"已提交"},
 {"op":"service","req":"r42","name":"git","op":"commit","arg":{"message":"fix: ..."}}]
```

视图 id 规范:插件注册的视图 = `<plugin_id>:<view>`;宿主持有,插件伪造不了别人的名字。

## 5. 宿主服务(v1 只有 git)

git 面板插件**不执行 git 进程**,复用 `services/git.rs` 现成函数受控暴露:

```
service:git → status / numstat / file_diff / stage / unstage / stage_all /
              commit / push / log / ahead_count   (参数校验:路径必须在 cwd 内)
```

这同时是给未来插件的样板:**宿主把已有能力包成 service,插件零进程权限**。

## 6. 持久化与生命周期

```
~/.pi-flash/plugins/
├── enabled.json          # {id: bool}
├── audit.log             # 能力调用审计
└── git-panel/
    ├── plugin.toml
    ├── git_panel.wasm
    └── data.json         # 插件私有数据(host_data_set 落盘,原子写 tmp+rename)
```

- **启动**:扫目录 → 解析 manifest → 双版本校验 → enabled 检查 → 实例化 → `load()`
  → 注册 dock/settings;全部在后台管线(§4 启动的 BackgroundFill 阶段),不阻塞首帧;
- **启用/停用**:settings-插件页开关,即时生效(enable=实例化+注册,disable=注销+drop),不重启;
- **trap**:调用 trap → 自动置 disabled + settings 页横幅展示错误;
- **升级**:市场下载新版 wasm 覆盖 → 重启实例(禁用→换文件→启用),data.json 保留。

## 7. 市场(Gitee monorepo + 应用内安装界面)

### 7.1 插件中心仓库(`https://gitee.com/bl_ddyy/pi-flash-plugins.git`)

**单仓库 = 插件中心**:monorepo 存多个插件项目源码 + 索引 + 制品,单仓库闭环,
不依赖 Release 附件;选 Gitee 避开 github 被墙(080 已知问题),raw 国内直连。

```
pi-flash-plugins/
├── plugins.json                    # 索引(唯一事实源)
├── git-panel/                      # 插件项目 1(独立构建,互不干扰)
│   ├── plugin.toml
│   ├── src/
│   └── dist/git-panel-0.1.0.zip    # 构建产物(含 wasm),索引指向它
├── another-plugin/
└── README.md
```

```jsonc
{
  "schema_version": 1,
  "plugins": [{
    "id": "git-panel",
    "name": "Git 面板",
    "description": "...",
    "version": "0.1.0",
    "authors": ["..."],
    "min_app_version": "0.1.0",
    "min_api_version": 1,
    "categories": ["面板"],
    "download": {
      "url": "https://gitee.com/bl_ddyy/pi-flash-plugins/raw/main/git-panel/dist/git-panel-0.1.0.zip",
      "sha256": "…",
      "size": 123456
    }
  }]
}
```

- 制品 zip(plugin.toml + wasm)提交在**��仓库**各插件项目的 `dist/` 下,
  索引 download.url 指向本仓库 raw 地址,sha256 随索引给;
- **PF 内置默认索引源** = `https://gitee.com/bl_ddyy/pi-flash-plugins/raw/main/plugins.json`,
  settings-插件页可改(自建镜像/私服);
- v1 只认索引源里的条目,**不开放任意 URL 安装**(恶意插件第一道闸)。

### 7.2 安装界面(settings-插件 tab)

复用 040 的版式骨架,分两区:

- **上区【插件市场】**:读默认索引源(ureq 后台拉,缓存 `~/.pi-flash/marketplace-cache.json`,
  手动刷新按钮;网络失败显示缓存+提示)。列表 = 名称/描述/版本/作者 + 安装按钮;
  已安装且最新 → 显示"已安装";索引版本 > 本地 → "更新"。
- **下区【已安装】**:左列表(名称+开关)右详情(版本/路径/能力声明/占用/打开设置页按钮/
  停用/卸载)。卸载 = 目录移回收站(项目约定防误删)。
- 安装流程:下载 zip → 边下边算 SHA-256(080 §3.2 同序)→ 校验 → 解压落位(条目名安全化)
  → 启用 → 出现在 dock。
- 开发者通道:`PI_FLASH_DEV_PLUGINS=<目录>` 启动时加载本地插件(跳过索引/校验,仅开发机用)。

## 8. SDK(插件项目侧)

- `pf-plugin-sdk` crate:ElementSpec builder(链式/宏)+ 事件反序列化 + data helper +
  `pf_plugin!` 入口宏(注册导出函数);插件项目一条命令出 wasm:
  `cargo build --release --target wasm32-wasip1`;
- 官方模板仓库:`pi-flash-plugin-template`(含 git 面板级完整示例);
- SDK 随宿主发版节奏走 git tag,pin 语义与 api_version 对齐。

## 9. 与现有模块的接线点

| 现有模块 | 接线 |
|---|---|
| function_panel/mod.rs | PanelTab 增 `Plugin{plugin_id, view}` 变体;插件项与内置项同享右键换边/badge 逻辑 |
| settings/mod.rs | 固定 tab 后追加动态 tab 区(插件注册的设置页);`nav_items` 扩展 |
| services/git.rs | 原函数不动,plugins/service 层包一层校验后调用 |
| theme/icon theme | ui.rs 渲染 ElementSpec 时按当前 ActiveTheme 取令牌,插件零感知 |
| startup.rs | 插件装载并入 BackgroundFill 管线 |
| check_arch | 单文件 ≤1500 行;新字符串 `tr()`;插件 UI 文案由插件自带(不进 i18n) |

## 10. 样板插件:git 面板(pi-flash-plugins 仓库内项目)

- 状态管理:插件内存持有 tab 选择/输入草稿;持久项(data.json):默认 tab、commit 模板;
- UI:头部 tabs(Changes/History)+ 文件 list(status badge + 名称 + +/- numstat,
  row_click = stage/unstage)+ 底部 input(消息)+ commit/push button;全部 §4 组件;
- 数据:启动 load 后 service:git 拉 status;commit/push 走 on_result 回灌;
- **内置 git_panel.rs 的去留**:插件成熟前内置保留并存;插件版达到 022 行为基线后
  单独拍板替换(替换时 022 文档改挂插件仓库)。
