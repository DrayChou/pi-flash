# 更新日志

所有对外发布的版本变化记录于此，格式见 `docs/CHANGELOG规范.md`。

## [0.1.5] - 2026-10-13

应用内更新补齐镜像切换与下载百分比，上下文用量弹层改版；一批 chrome 对齐微调。

### 安装与更新

```bash
npm install -g pi-flash@latest   # 首次安装与更新同命令
pi-flash
```

需要 Node.js ≥ 22.19。
也可直接下载 zip 绿色包，解压后双击 `pi-flash.exe` 即用，无需 Node。
仅提供 Windows x64 版本。

### 新增
- 应用内更新测速切镜像：下载载荷直连测速（开传 3 秒均值 <128KB/s 即弃），按序切换镜像直至命中；校验和直连钉定官方哈希防串包。`PI_FLASH_MIRROR` / `PI_FLASH_MIRRORS` 与安装器同规则。(6734db6)
- 应用内更新显示下载百分比：版本号位原地刷新 NN%（服务器未给 content-length 时省略）。(8e82205)
- 上下文用量弹层改版：标题行（已用 / 窗口 · 百分比）+ 进度条 + 分类占比行（7 档估算、降序色点）+ 缓存命中率；420px 二列网格，token 千分位。(bf03158, c17247c, 6b6c827, a618b1c)

### 修复
- 键位提示假键位：Ctrl+P / N / K 的 tooltip 曾可能显示 Win+P 这类假键位（gpui 的 cmd 是 platform 修饰键），cmd-* 孪生绑定已删。(d63039e)

### 改进
- chrome 对齐一批（用户定夺）：topbar 与 statusbar 等高 40px（窗口控制钮 42×40 跟随）；bar tab 高度贴合；状态栏设置钮右缘对齐列表右线、首 tab 卡片左缘落图标对齐线；图标对齐线收敛单一令牌（11→12px）；composer 右组按钮间距与左组一致（15px）。(d2760c5, c100b22, 61981c5, 418512c, d00de94, e015300, 189008a)

## [0.1.3] - 2026-10-13

会话侧栏即时反馈 + 下载链路加速：伪标签秒现、下载慢自动切镜像。

### 安装与更新

```bash
npm install -g pi-flash@latest   # 首次安装与更新同命令
pi-flash
```

需要 Node.js ≥ 22.19。
也可直接下载 zip 绿色包，解压后双击 `pi-flash.exe` 即用，无需 Node。
仅提供 Windows x64 版本。

### 新增
- 会话侧栏伪标签：新会话发出首条消息的瞬间，侧栏立即出现新会话标签（转圈 + 消息首行预览），落盘后自动换成真实标签；消息被拒 / 进程退出 / 未产生会话文件时占位自动撤除，不挂永远不会变真的标签。(5914900)
- 下载测速自动切镜像：安装 / 更新拉取载荷时直连测速，过慢自动按序切换 gh-proxy.com / ghfast.top / ghproxy.net 镜像；下载行原地刷新百分比与速度，30 秒无活动超时兜底。`PI_FLASH_MIRROR` 仍可钉定唯一源。(8b2048e)

### 修复
- 启动恢复：没说话就关闭应用，下次启动不再丢上一个会话（pi 构造期提前上报 sessionFile、会话文件本体未落盘导致的"幻影路径"不再绑定）。(5914900)

### 改进
- 下载残留清理：启动与下载前按进程存活清理半截下载（payload.tmp-* / update.tmp-*），历史残留一并清除；校验和直连取官方源哈希、zip 走镜像，防镜像串包。(8b2048e)
## [0.1.2] - 2026-10-12

终端与文件编辑体验修复批次：补齐终端复制粘贴、修掉一批实测界面问题，HTML 文件改为编辑器内源码打开。

### 安装与更新

```bash
npm install -g pi-flash@latest   # 首次安装与更新同命令
pi-flash
```

需要 Node.js ≥ 22.19。
也可直接下载 zip 绿色包，解压后双击 `pi-flash.exe` 即用，无需 Node。
仅提供 Windows x64 版本。

### 新增
- 终端复制粘贴入口：右键菜单（复制 / 粘贴 / 全选）+ Windows 习惯键——Ctrl+C 有选区即复制（无选区仍是 ^C 中断）、Ctrl+Shift+C / Ctrl+Insert 复制、Shift+Insert 粘贴、Ctrl+Shift+A 全选。(9daa12c)
- 终端选区：双击选词、三击选整（逻辑）行；拖选拖出终端边缘自动滚动。(1c68a5b)
- 终端选区编辑：有选区时 Backspace / Delete 一次删除整个选区，粘贴直接替换选区。(3afb8a3)
- 设置新增「自动折叠时间」：1 / 3 / 7 天档位，启动时自动折叠超时未活动的项目组。(e03659e)

### 修复
- 终端：开多个终端后切换标签，键盘输入不再打进后台终端；点标签即聚焦，不用再点一次终端。(80ede11)
- 终端：项目菜单「在终端中打开」不再把左侧面板切到文件树；同一项目可开多个终端，不再只跳到已开的那个。(73173bd)
- 会话：切换或新建会话时内容区自动回到会话视图，不再停在终端 / 文件页。(badaed6)
- 会话：新会话发出首条消息后侧栏立即出现新标签，不用等整轮回复跑完。(23506b7)
- 会话：轮末通知点判定收紧——出错的轮次不再显示为完成（青蓝），个别工具报错不再让整轮标红。(faee211)
- 会话列表：标题显示 "(empty)" 的问题——系统提示词行或超大粘贴把首条消息挤出索引时，现在能抢救出前 50 字符作为预览。(fff7f8a)
- 会话：自动重试的退避窗口（2–8 秒）里界面误显为空闲——现在保持「运行中」，状态行提示「出错，Ns 后自动重试（第 x/y 次）」。(0747542)
- Markdown 渲染：列表项里的行内 `code`、粗体、链接整段丢失（只剩标点）。(cd7528c)
- 编辑器：大 HTML 文件（118KB 设计稿实测）语法高亮从每帧 8 秒卡顿修复到流畅。(382ab0b)
- 图片：结果图 / 大图预览按比例缩放，去掉上下留白。(05317a0)
- 设置：「展示思考」的描述在繁体 / 英文界面误显示中文。(0f50b2c)
- 项目卡片：改名时点击卡片外部即取消，不再强制完成改名或回车。(2bc46de)
- 任务栏图标四周多一圈留白——ico 按九档尺寸满画布重新生成。(7ad6c63)

### 改进
- HTML 文件直接在编辑器中以源码打开（语法高亮、可编辑、参与自动保存），「在浏览器中打开」保留为右键菜单首位动作。(8fd3bcf, e3e3dd5)
- 完成提示音换为 PF 原创暖木琴双音（A4→E5），听感更厚实温和。(4cba884)
- 新增 i18n 漏译守卫：界面文案漏配繁体 / 英文译文时测试直接失败，不再静默回落中文。(ed2e126)
