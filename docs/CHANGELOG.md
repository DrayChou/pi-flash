# 更新日志

所有对外发布的版本变化记录于此，格式见 `docs/CHANGELOG规范.md`。

## [0.1.8] - 2026-10-15

消息区划选复制与文件树拖拽移动落地；composer 滚动、会话滚轮、文件树行内改名一批交互修复。

### 安装与更新

```bash
npm install -g pi-flash@latest   # 首次安装与更新同命令
pi-flash
```

需要 Node.js ≥ 22.19。
也可直接下载 zip 绿色包，解压后双击 `pi-flash.exe` 即用，无需 Node。
仅提供 Windows x64 版本。

### 新增
- agent 消息划选复制一期：定稿消息块改用 TextView 渲染，支持划选复制与右键复制菜单；可点文件路径改链接样式（链接色+下划线，浅色主题下可见）；表格渲染修正一批（列宽按显示宽度加权、列位漂移、格内折行、表头加粗）。(eea59ce, dfa56dd, ef2d66c, 2b075ba, b013e6d, 585c594, 08d7051, 9c0bee6, 144fdd7)
- 文件树拖拽移动：拖文件/目录到目标目录即移动，悬停折叠目录 500ms 自动展开（Zed project_panel DnD 同构）。(e695eab)
- 设置「文档字体」档位扩充 16/18/20/22（其余槽位 15/16/17/18 不动），全部字号槽统一钳制 10–30。(907a8b7)

### 修复
- composer 多行光标移动鬼畜：视口较矮时滚动位逐键翻转、行高 3↔4 交替（vendor scroll_to 上下安全区重叠永不收敛），兼治光标贴底行把首行裁出视口。(79910c6)
- 会话区滚轮失灵：短内容稍滚即跳底且滚动余量归零；现滚轮只暂停贴底重钉，滚回贴底自动恢复跟随，读历史不被流式输出拽走。(386896b)
- 折叠项目组里新建的会话凭空消失：新会话落地自动展开所在组（fork/微信端新会话同经此处）。(26057ea)
- 文件树行内改名视觉四修：1px 抖动（行框边框恒挂透明占位）、文字上跳 1px、字体/字号突变（随面板字体档）、文字多缩进 4px。(b0b6224, b686892, fec33d0, 08f1c31, 09a8437)
- 编辑器主体字体随设置「文档字体」槽位（原硬编码 JetBrains Mono）；行距对齐 Zed Comfortable 档（1.618，原恒 1.25rem 过密）。(d5eddae, 0323612)

### 改进
- 会话行详情卡改右键召唤：悬停自动弹窗机制整体撤除（交互修不平，用户定夺）；右键开卡、点卡外即收、光标不压卡防误点。(64ab3f4)
- composer 扩展钮 plug 图标 13→16（规范中档）。(0a1dd18, 2d3a36e)

### 改进
- 图标与 chrome 对齐一批（用户定夺）：icon_hover 的 +2px 绘制膨胀拔除（同名尺寸比 icon() 大 2px 的「图标乱」根因），全站位点回归设计稿档位真值；控制栏右二与文件树操作栏列对齐（26×26 / 间距 2）；「会话」icon 18→19 光学补偿；状态栏设置钮 / 项目 tab 升大图标档；项目行路径悬浮条关闭。(ed419c0, 8ec6754, edf5267, 9257cd5)
## [0.1.6] - 2026-10-14

编辑器打开能力批次：图片直接打开、GBK/UTF-16 等遗留编码可开可存；标签右键菜单与更新日志入口；大单行文件假死与中文崩溃修复；滚屏手感对齐 Zed。

### 安装与更新

```bash
npm install -g pi-flash@latest   # 首次安装与更新同命令
pi-flash
```

需要 Node.js ≥ 22.19。
也可直接下载 zip 绿色包，解压后双击 `pi-flash.exe` 即用，无需 Node。
仅提供 Windows x64 版本。

### 新增
- 图片文件直接打开：打开路由按文件头识别（此前含 NUL 字节一律灰屏，png 等图片永远轮不到渲染），png/jpg/gif/webp/bmp 等以图片 tab 呈现，补齐 tiff/ico/pnm 后对齐 Zed 八格式全集；svg 归源码态打开（预览是单独动作，随后再议）。(f8046cd, b8ba388)
- 遗留编码可开可存：打开文本走编码检测管线（BOM / UTF-16 NUL 分布 / chardetng 嗅探 + magic 头表，zed file_content 逐字移植），GBK、UTF-16LE 的 .reg 等文件可开，保存按原编码写回、往返保持。(f8046cd)
- 标签右键菜单：关闭 / 关闭其他 / 关闭左侧 / 关闭右侧 / 全部关闭（zed 同款）；批量关闭时多个脏文件收进一个确认弹窗（保存并关闭 / 不保存关闭对整批生效）；首个会话标签恒不可关。(11331e6)
- 新会话页版本号点击开更新日志：Idle 淡字版本号可点击，读本地缓存、缺失按 tag 现拉；更新日志拉取失败改 15s 超时并显示「暂时无法连接 GitHub」，再点即重试，不再干等 30s 落成误导性「暂无更新日志」。(e423e6b, 4a480f6)

### 修复
- 大单行文件假死：打开 min 过的前端产物（如 echarts.min.js，末行 94 万字符）每帧分钟级冻结——语法高亮与文字 shaping 裁到视口字节窗后恢复毫秒级。(1d30077)
- 中文文件崩溃与高亮错位：视口裁剪后样式区间不再覆盖整段可见文本，含中文的文件从多字节字符中间切开直接崩溃（0xc0000409），ASCII 文件高亮悄悄错位——窗前窗后补默认样式 filler 恢复平铺不变式。(17138f2)
- Markdown 折行回归：关 WYSIWYG 曾连坐关闭软换行，现两者解耦，源码编辑折行恢复恒开（与预览状态一致）。(b654ae8)
- 更新后首启的「新版本」弹窗记账：开发/冒烟构建不再写 last_seen，此前跑一版就污染记账，正式版更新后的首启弹窗会被吞。(dab6fe7)

### 改进
- 滚屏手感对齐 Zed：视口内高亮每帧重跑 query 与逐捕获堆分配清零（差分测试全等校验）、滚轮每 tick 双帧消除、行高吸附整设备像素（1.5× 缩放下亚像素抖动发虚）；大文件滚动 app 侧开销基本清零。(35836ff)
